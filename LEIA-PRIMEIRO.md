# Modo Celular — leia primeiro (para humanos)

Este vault ensina um agente de código (Claude Code, Codex, Cursor...) a
trabalhar do jeito que uma pessoa neurodivergente funciona melhor: em
**células pequenas de foco**, com **estado sempre anotado** para que parar
nunca custe caro e retomar seja quase instantâneo.

## A filosofia em cinco linhas

1. Trabalho acontece em células: unidades pequenas, com fronteira e contrato.
2. Cansar não é falhar — é o fim natural da célula. O protocolo acolhe isso.
3. Tudo que importa vira anotação: **retomável ⟺ anotado**.
4. O percurso pode ser não-linear; o registro garante que o resultado converge.
5. O agente segura a coerência global para que a pessoa gaste energia só no foco.

## As duas camadas do pacote

- **A LEI** — `SKILL-METODO-TMULAB.md` (raiz): engenharia rigorosa — testes
  antes, verificação trilateral, dados DIAMOND, disciplina de decisão.
- **O MODO** — `vault/` + skills: células, estado, retomada, energia.

O `CLAUDE.md` compõe as duas; em conflito de regra de código, a lei vence.

## Instalação (2 passos)

1. Copie TODO o conteúdo desta pasta para a **raiz do seu projeto**
   (incluindo as pastas ocultas `.claude/`).
2. Abra o projeto no seu agente e diga `/celula`. Pronto.

Este vault vem preenchido com o perfil e as regras do Hudson como exemplo
vivo. Para torná-lo seu: leia `vault/06-adaptacao.md` — ele diz exatamente
o que é protocolo genérico (fica) e o que é perfil pessoal (você troca).
Leva menos de meia hora e o vault passa a ser seu.
