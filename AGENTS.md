# Modo Celular

Este projeto segue o Modo Celular (trabalho em células com estado anotado).
Leia `CLAUDE.md` na íntegra e siga exatamente as mesmas regras — ele é o
arquivo de entrada canônico deste modo, válido para qualquer agente.

Regra mínima se você não puder ler mais nada: uma célula por vez; build antes
de entregar; nada destrutivo ou em lote sem aprovação explícita; ao fim,
atualizar `vault/estado/` conforme `vault/01-celulas.md`.
